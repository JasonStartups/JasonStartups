# Charles E. Jason

### Founding AI Engineer · AI Systems Architect · Product Builder

I build AI-native products and the software systems behind them.

My work sits at the intersection of **LLM systems, agentic workflows, backend engineering, and product development**. I enjoy taking ideas from technical architecture to working software, especially where AI can solve practical problems for businesses and people.

## What I Build

- **AI agents:** Tool use, workflow orchestration, agentic systems, and integrations.
- **LLM applications:** Retrieval-augmented generation (RAG), embeddings, context engineering, and evaluation.
- **AI infrastructure:** MCP servers, APIs, enterprise integrations, and reliable execution pipelines.
- **Backend systems:** Python services, API design, databases, and distributed-system patterns.
- **AI-native products:** Technical architecture, prototyping, product development, and deployment.

## How I Think About Engineering

Connecting an application to an LLM is only the beginning.

Useful AI products need sound architecture, reliable tool execution, evaluation, observability, security, and a clear understanding of the problem they are solving. I value practical engineering, fast iteration, and taking ownership from idea to implementation.

I'm especially interested in working with ambitious early-stage teams building products where AI is central to the experience.
